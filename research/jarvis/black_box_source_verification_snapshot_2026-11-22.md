### JARVIS Black Box control matrix
| Input state | Required verification | Permissible output |
|---|---|---|
| `SENT` | Original sent ID, exact scope/date | A send-event record only |
| `AUTO_ACK` | Original response + thread | Acknowledgment, not review |
| `HUMAN_REPLY` | Original human-authored response | Quoted intent with limitations |
| `EXPLICIT_INVITATION` | Specific affirmative invitation | One scoped, privacy-preserving dialogue where invited |
| `ENDORSEMENT` | Explicit written acceptance and identity checks | A narrowly characterized accepted activity |
| `PRIVATE_TESTIMONY` | Exact attributed original statement | Respectful preserved personal account, no inferred external mechanism |
| `UNVERIFIED_HIGH_CONSEQUENCE_CLAIM` | Independent corroboration and testable mechanism absent | No alarm, no mass outreach, no military activation, no automatic claim propagation |

**Disconfirming evidence matters.** Document contradictory correspondence and negative outcomes, especially when an earlier automated message suggested that an institution might arrange a review but a later human representative declined or clarified its limitations.

### Global contact rules

Physical/military emergencies require credible concrete evidence and legitimate human reporting rather than computer-generated speculative escalation.
